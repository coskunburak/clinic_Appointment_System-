# S10 — Rapor, GitHub/SABİS ve sınıf içi sunum

**Amaç:** Ödevin bütün teslim şartlarını somut kanıtla karşılamak; akademik sunum/demoyu prova etmek.

**Süre:** 2–3 gün (+ son 4 haftadaki sunum tarihi) · **Önkoşul:** S09 UAT temiz; 10 farklı gerçek gün ilerlemesi tamamlanmış olmalı. · **İlişkili gereksinimler:** NFR-006 NFR-007

**Sahiplik:** A ve B ortak; tek kişi tamamını yapar

## Görevler / uygulama sırası
1. Gerçek commit tarihlerini say; 10 farklı gün şartı yoksa sahte tarih üretme, gerçek günlere yeni anlamlı çalışma planla.
2. README: kapsam, teknolojiler, kurulum, demo roller, ekran görüntüleri, test, sınıf diyagramı, sınırlılıklar.
3. Kısa rapor: problem, OOP eşleştirme, mimari, ER, kritik booking algoritması, test kanıtları.
4. 6–8 slayt hazırla; 5–7 dakikalık demo kurgusu prova et (gerçek sunum süresi öğretim elemanına bağlı).
5. GitHub erişimini doğrula; ZIP/repo linki ve gerekirse SABİS yükleme dosyasını süre dolmadan gönder.
6. Sunuma katıl; gerekli dosyaları offline olarak yanında tut.

## En az incelenecek kaynak/yol (önerilen, mevcut olduğu teyit edilmeden varsayma)
- `README.md`
- `docs/08-teslim/02-sunum-ve-demo.md`
- `docs/08-teslim/03-proje-raporu-iskeleti.md`
- `docs/08-teslim/01-github-commit-takvimi.md`

## Sprint kabul kriterleri / Definition of Done
- [ ] GitHub repo doğru erişimde, 10+ gerçek farklı tarih commit mevcut.
- [ ] SABİS yükleme yapıldı ve yükleme kanıtı tutuldu.
- [ ] OOP class diagram + örnek kod + üç rol + çakışma demo gösteriliyor.
- [ ] Sunum katılım koşulu karşılanır; başarı iddiası yalnız kanıta dayanır.
- [ ] İlgili negatif testler ve görev gerektiriyorsa migration çalıştı (öğrenci bildirdi).
- [ ] Sadece gerekli belgeler güncellendi; geniş kapsamlı refactor yapılmadı.
- [ ] `git diff --check` ve çalışma ağacı kontrol edildi.
- [ ] Öğrenci gerçek gün commit/push gerçekleştirdi (yapıldıysa kanıt verildi).

## Kanıt/çıktı
- git log date check
- GitHub URL
- SABİS ekran kanıtı
- slayt + demo kontrolü

## Risk / kontrol
Sunuma gelmeme puan kaybı ve 10 ayrı gün kuralı; takvim önceden yönetilir.

## Öğrencinin manuel çalıştıracağı örnek komutlar

```bash
git log --format=%as | sort -u | wc -l
git status --short
git diff --check
```

**Not:** Bu komutlar yalnız ilgili repo ve sprintte dosyalar oluştuysa kullanılabilir. Ajan komutları tek blok halinde verir, asla test koştuğunu iddia etmez.

Bu sprint yalnız yukarıdaki iş ve NFR-006 NFR-007 kapsamını kapsar. Sprint çıkışı için S10 kabul kutularının hepsi gerçek kanıtla tamamlanmalıdır.
