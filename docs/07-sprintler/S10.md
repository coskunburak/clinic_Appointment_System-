## 2. Detaylı İş Paketleri (Work Packages)

### WP-S10-01: Git Geçmişi ve Gün Denetimi
1. Takvim günlerinin doğrulanması:
   ```bash
   git log --format='%h %as %s' --reverse
   git log --format=%as | sort -u
   ```
2. Tüm değişikliklerin `origin/main` dalına `git push` ile gönderildiğinin teyidi.

### WP-S10-02: SABİS Teslim Arşivi Hazırlığı
1. Geçici ve gizli dosyaların temizlenmesi:
   ```bash
   ./mvnw clean
   git status -s
   ```
2. Depo zip arşivinin oluşturulması:
   - Kaynak kodlar (`src/`), Maven Wrapper (`mvnw`, `.mvn/`), `pom.xml`, `compose.yaml`, `.env.example`, `README.md` ve `docs/` eksiksiz dahil edilir.
   - `.env`, `target/`, `.DS_Store` kesinlikle arşive girmez.

### WP-S10-03: Canlı Sunum ve Savunma Provasi
1. Slayt setinin tamamlanması:
   - Slayt 1: Kapak ve Kimlik
   - Slayt 2: Gereksinimler & Kapsam
   - Slayt 3: Teknoloji & Modüler Monolit
   - Slayt 4: OOP Kanıtları (Kalıtım, Polimorfizm, Kapsülleme, SOLID)
   - Slayt 5: Çakışma Önleme, Pesimist Kilit & Snapshot
   - Slayt 6: Test Kanıtları & 10 Gün Commit Grafiği
   - Slayt 7: Canlı Demo & Sonuç
2. Çevrimdışı çalışma provası: Docker PostgreSQL konteyneri açıkken internet bağlantısı kesilerek tarayıcı üzerinden 5 dakikalık senaryo koşturulur.
