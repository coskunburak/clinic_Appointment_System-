# S09 — Regression, hardening ve tekrarlanabilir demo

**Amaç:** Kritik hataları kapatmak, güvenlik/performans/regression doğrulamak ve fresh clone kurulumu ispatlamak.

**Süre:** 3–4 gün · **Önkoşul:** S08 kullanıcı akışı tamamlanmış. · **İlişkili gereksinimler:** FR-034 NFR-004 NFR-005 NFR-008 NFR-010

**Sahiplik:** A backend/performance; B UX/security/UAT

## Görevler / uygulama sırası
1. FR-MUST checklist üzerinde her satırı teste bağla; regression suite çalıştırılacak komutları teslim et.
2. Testcontainers concurrent requests; role IDOR; invalid hours; DST; price snapshot; state transitions tekrar doğrula.
3. Kurmaca demo seed/reset yalnız dev profile; 1000 appointment/50 staff lokal performans hedefini ölç.
4. Fresh clone / Docker / migrate / run / login/smoke prosedürünü başka makine veya temiz dizinde uygula.
5. Hata logunda PII/şifre görünmediğini, template escapes ve CSRF'yi manuel doğrula.
6. Blocker bugfix dışında yeni modül ekleme; release candidate tag isteğe bağlı.
