# S02 — Saf domain modeli ve OOP kanıtları

**Amaç:** Kalıtım/kapsülleme/çok biçimlilik ve domain invariants için test edilebilir sınıf sözleşmeleri kurmak.

**Süre:** 2–3 gün · **Önkoşul:** S01 build ve migration. · **İlişkili gereksinimler:** FR-016 NFR-010

**Sahiplik:** A domain; B varsa unit tests ve UML review

## Görevler / uygulama sırası
1. PersonProfile abstract ortak alanlarla kapsülleme; PatientProfile ve StaffProfile inheritance göster.
2. Money immutable BigDecimal/ISO currency value object, miktar ve para birimi kontrolleri.
3. Appointment davranışlarına status transition, snapshot ve half-open interval invariant ekle.
4. SchedulingConstraint interface + en az iki somut policy ile polymorphism kanıtla.
5. Repository/service/controller sorumluluklarını ayır; JPA entity ilişki gerilimini ADR ile belgele.
6. Domain unit testleri: invalid money, negative duration, state transitions, interface substitute.
