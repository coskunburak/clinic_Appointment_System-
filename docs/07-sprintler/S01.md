# S01 — Java Bootstrapping ve Veritabanı Temeli

**Amaç:** Uygulama iskeletini gerçek PostgreSQL 17 + Flyway üzerinde tekrar üretilebilir başlatmak, JPA kalıcılık tabanını oluşturmak, Testcontainers entegrasyon testlerini ve CI iş akışını yapılandırmak.

**Süre:** 2–3 gün · **Önkoşul:** S00 scope onayı (Commit `23b7d28`). · **İlişkili gereksinimler:** NFR-003, TC-039

**Sahiplik:** Backend / Veritabanı Mimarı / Test & CI Mühendisi

## Görevler / Uygulama Sırası
1. **Bağımlılıklar (`pom.xml`):** Spring Boot 3.4.2 ve Java 21 temelinde `spring-boot-starter-data-jpa`, `postgresql`, `flyway-core`, `flyway-database-postgresql`, `spring-boot-starter-actuator`, `spring-boot-testcontainers`, `testcontainers:postgresql` ve `maven-failsafe-plugin` yapılandırıldı.
2. **Konteyner Ortamı (`compose.yaml` & `.env.example`):** PostgreSQL 17 Alpine imajı, kalıcı volume (`postgres_data`), sağlık denetimi (`pg_isready`), yerel port eşlemesi (`127.0.0.1:5432:5432`) ve güvenli `.env.example` şablonu oluşturuldu.
3. **Konfigürasyon Profilleri (`application*.yml`):**
   - `application.yml`: UTF-8, Thymeleaf, `spring.jpa.hibernate.ddl-auto=validate`, `flyway.enabled=true`, Actuator `/actuator/health` güvenli yapılandırması. Eski `application.properties` kaldırıldı.
   - `application-dev.yml`: Yerel PostgreSQL ve SQL debug loglaması.
   - `application-test.yml`: Test profili ve Testcontainers dinamik veri kaynağı entegrasyonu.
4. **Flyway V1 Migrasyonu (`V1__create_organization_and_identity.sql`):** `organization`, `branch`, `branch_opening_hours`, `department`, `user_account`, `membership`, `patient_profile`, `staff_profile` tabloları, indeksler, kısıtlar (CHECK, UNIQUE, kompozit kiracı FK `fk_membership_branch_org`) eklendi.
5. **JPA Kalıcılık Tabanı:** `Organization`, `Branch`, `Department`, `BranchOpeningHours`, `UserAccount`, `Membership`, `PatientProfile`, `StaffProfile` entity ve Spring Data JPA repository arayüzleri yazıldı. Şifre hash'i `toString()` çıktısından hariç tutuldu.
6. **Entegrasyon ve Bütünlük Testleri:**
   - `ClinicAppointmentApplicationTests`: Uygulama context ve JPA validate smoke testi.
   - `FlywayMigrationIT`: TC-039 Flyway sıfırdan kurulum, idempotency ve şema doğrulama testi.
   - `OrganizationRepositoryIT` & `IdentityRepositoryIT`: Gerçek PostgreSQL persistence testleri.
   - `DatabaseConstraintIT`: Negatif benzersizlik, yabancı anahtar ve çoklu kiracı sınır testleri.
7. **GitHub Actions CI (`.github/workflows/ci.yml`):** Java 21 Temurin, Maven cache, Docker/Testcontainers desteğiyle `./mvnw -B verify` adımı eklendi.

## Risk / Kontrol
- **Docker Gereksinimi:** Testcontainers ve yerel PostgreSQL Docker motoru gerektirir. Docker Desktop veya Colima çalışır durumda olmalıdır.
- **Java 21 Uyumu:** macOS üzerinde terminal varsayılanı Java 17 olduğunda `JAVA_HOME` açıkça Java 21'e yönlendirilmelidir (`/opt/homebrew/opt/openjdk@21`).
- **Failsafe Entegrasyonu:** `*IT.java` testlerinin `mvn verify` safhasında Failsafe tarafından otomatik koşulması sağlandı.
