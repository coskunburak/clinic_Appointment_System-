# S08 — Üç rol için tamamlanmış web arayüzü

**Amaç:** Tüm temel kullanıcı yolculuğunu demo edilebilir Spring MVC/Thymeleaf ekranlarıyla bitirmek.

**Süre:** 4–5 gün · **Önkoşul:** S03–S07 tamamlanmış business flow. · **İlişkili gereksinimler:** FR-027 FR-028 NFR-009

**Sahiplik:** B UI/MVC; tek kişiyse öğrenci A; A backend review

## Görevler / uygulama sırası
1. Hasta login/dashboard/şube→hizmet→personel→tarih→slot→fiyat preview→PENDING akışı.
2. Personel pending listesi ve approve/reject/complete formları; yetkili olmayan kaydı gizle.
3. Yönetici şube/saat/bölüm/hizmet/süre/ücret/personel/uygunluk temel CRUD ekranları.
4. DTO, bean validation, CSRF, POST/Redirect/GET, temiz hata mesajları ve boş liste durumları.
5. UI tema ve erişilebilir label, klavye, Türkçe locale, offline Bootstrap.
6. MockMvc security testleri; manuel 3 rol smoke demo.
