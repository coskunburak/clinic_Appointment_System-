# Issue / PR / sprint review şablonları

## Issue
```markdown
## Hedef
[FR-ID] — kısa kullanıcı değeri
## Kapsam
- Değiştirilecek sınıflar/dosyalar:
- Bağlı veri/migration:
- Kapsam dışı:
## Kabul kriterleri
- [ ] Mutlu akış
- [ ] Negatif/permission/validation akışı
- [ ] TC-ID kanıtı
## Risk ve geri dönüş
## Sprint / sorumlu
```

## PR
```markdown
## Özet / ilişkilendirilen Issue
## Değişen modüller
## Migration / güvenlik / veri etkisi
## Eklenen testler (yalnız gerçek sonuç)
## Manuel test komutları
## Ekran görüntüsü / demo kanıtı
## Geriye uyumluluk ve doküman güncellemesi
```

## Sprint review
```markdown
Sprint ID:
Issue'lar:
Commit SHA ve gerçek gün:
Kapsanan FR/TC:
Kod yolları:
Öğrenci çalıştırdığı komutlar:
Öğrenci test sonuçları:
Bilinen kusurlar:
Bir sonraki sprintin koşulları:
```
