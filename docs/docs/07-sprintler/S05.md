# S05 — Personel yönetimi, yetkinlik ve müsaitlik

**Amaç:** Uzmanlık, şube ataması, hizmet yetkinliği, haftalık program ve izin istisnalarını modellemek.

**Süre:** 3–4 gün · **Önkoşul:** S03 katalog; S04 identity ve yetki. · **İlişkili gereksinimler:** FR-007 FR-008 FR-009 FR-010 FR-011

**Sahiplik:** A staff/scheduling; B varsa admin forms

## Görevler / uygulama sırası
1. StaffProfile type ve doktor specialty validation; StaffAssignment(branch,department) ekle.
2. StaffServiceEligibility ile yalnız aynı branch service için yetkilendir.
3. WeeklyAvailability ve AvailabilityException (tam gün/interval izin) şemasını uygula.
4. Aday slot sorgusu: branch opening ∩ weekly availability – exception; service duration sığmalı.
5. Kural zincirine OpeningHours, StaffAvailability ve StaffService constraint ekle.
6. İki şube aynı staff'a atanınca personel düzeyindeki çakışma politikasını belgele.
