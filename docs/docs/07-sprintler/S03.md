# S03 — Kurum, şube, bölüm ve hizmet kataloğu

**Amaç:** Tek ve çok şubeli kurumun çalışma saatleri ile ücret/süreli hizmet katalog yönetimini tamamlamak.

**Süre:** 3–4 gün · **Önkoşul:** S02 Money, temel domain. · **İlişkili gereksinimler:** FR-001 FR-002 FR-003 FR-004 FR-005 FR-006

**Sahiplik:** A backend/katalog; B varsa admin temel UI

## Görevler / uygulama sırası
1. Organization, Branch(timeZone), Department ve BranchOpeningHours modelle; org/branch bağlarını koru.
2. ServiceDefinition ve BranchService süresi, BigDecimal ücreti, currency, active flag uygula.
3. Çalışma saatleri ve branch-scoped unique kontrolleri ekle; gece mesaisini açıkça reddet.
4. Admin servislerini ve DTO/form validasyonunu yaz; controller erişimini şimdilik güvenli role shell ile sınırla.
5. Unit ve repository integ testlerle iki şube, farklı fiyat/süre, invalid saat doğrula.
6. Henüz booking veya SMS/e-posta ekleme.

## Sprint kabul kriterleri / Definition of Done
- [ ] Yönetici birden fazla şube/bölüm oluşturabilir.
- [ ] Aynı hizmet Merkez 30dk/800 TRY ve Sahil 20dk/650 TRY olabilir.
- [ ] Negatif ücret, sıfır süre ve end<=start reddedilir.
- [ ] Şube verisi başka kurumdan listelenmez.
- [ ] İlgili negatif testler ve görev gerektiriyorsa migration çalıştı (öğrenci bildirdi).
- [ ] Sadece gerekli belgeler güncellendi; geniş kapsamlı refactor yapılmadı.
- [ ] `git diff --check` ve çalışma ağacı kontrol edildi.
- [ ] Öğrenci gerçek gün commit/push gerçekleştirdi (yapıldıysa kanıt verildi).
