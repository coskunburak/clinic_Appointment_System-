# S01 — Java Bootstrapping ve veritabanı temeli

**Amaç:** Uygulama iskeletini gerçek PostgreSQL + Flyway üzerinde tekrar üretilebilir başlatmak.

**Süre:** 2–3 gün · **Önkoşul:** S00 scope onayı. · **İlişkili gereksinimler:** NFR-003

**Sahiplik:** A backend/DB; B varsa CI/README

## Görevler / uygulama sırası
1. Spring Initializr ile Boot 4.1.x Java 21 Maven Wrapper; `webmvc`, Thymeleaf, security, data-jpa, validation, PostgreSQL, Flyway, test starter seç.
2. Başlangıç bileşen sürümleri ve Boot 4 starter koordinatlarını resmî referanstan doğrula.
3. Docker Compose PostgreSQL 17 ortamı ve dev/test environment değişkenlerini ekle.
4. Organizasyon/identity tablolarını V1 migration olarak oluştur; JPA `ddl-auto=validate`.
5. Dış konfigürasyon için profil ayrımı ve health endpointin yetkisini tasarla.
6. Uygulama ve repository test iskeletini oluştur; GitHub Actions verify ekle.
