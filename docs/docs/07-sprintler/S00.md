# S00 — Kapsam dondurma ve GitHub hazırlığı

**Amaç:** Ödev gereksinimlerini ölçülebilir sözleşmeye çevirip ilk gerçek günlük commit ve repository iskeletini hazırlamak.

**Süre:** 1–2 gün · **Önkoşul:** Öğretim elemanının Seçenek A metni; Java seçimi. · **İlişkili gereksinimler:** NFR-006

**Sahiplik:** Öğrenci A; iki kişiyse B doküman review

## Görevler / uygulama sırası
1. Yeni GitHub repo oluştur; `docs/` içeriğini ekle; Java 21, web arayüzü, DB kararlarını ADR ile kaydet.
2. FR ile TC numaralarını gözden geçir; MUST dışı scope sıralamasını doğrula.
3. Kurum/şube/çalışan/hasta ana aktör akışını ve ölçülebilir demo senaryosunu seç.
4. README, LICENSE tercihi, `.gitignore` (target, .env, IDE, dump) ve issue etiketlerini oluştur.
5. Gerçek günün tarihli ilk commitini push et; kanıtı takip tablosuna işle.

## En az incelenecek kaynak/yol (önerilen, mevcut olduğu teyit edilmeden varsayma)
- `README.md`
- `docs/README.md`
- `docs/01-urun/01-gereksinim-matrisi.md`
- `docs/02-mimari/04-mimari-kararlar.md`
- `.gitignore`

## Sprint kabul kriterleri / Definition of Done
- [ ] Tüm öğretim elemanı gereksinimleri tek matristedir.
- [ ] Repo açılır; docs bağlantıları çalışır.
- [ ] MVP kapsamında ödeme/e-Nabız/tanı yoktur.
- [ ] İlk gerçek gün commit sayılır; sahte/biriktirilmiş backdate yapılmaz.
- [ ] İlgili negatif testler ve görev gerektiriyorsa migration çalıştı (öğrenci bildirdi).
- [ ] Sadece gerekli belgeler güncellendi; geniş kapsamlı refactor yapılmadı.
- [ ] `git diff --check` ve çalışma ağacı kontrol edildi.
- [ ] Öğrenci gerçek gün commit/push gerçekleştirdi (yapıldıysa kanıt verildi).

## Kanıt/çıktı
- GitHub repo URL
- FR matrisi kontrolü
- ADR onayı
- git log gerçek gün kaydı

## Risk / kontrol
MVP kapsamının şişmesi; ek özellik issue açılıp COULD seviyesine atılır.

## Öğrencinin manuel çalıştıracağı örnek komutlar

```bash
git status --short
git diff --check
git log --format=%as | sort -u | wc -l
```

**Not:** Bu komutlar yalnız ilgili repo ve sprintte dosyalar oluştuysa kullanılabilir. Ajan komutları tek blok halinde verir, asla test koştuğunu iddia etmez.
