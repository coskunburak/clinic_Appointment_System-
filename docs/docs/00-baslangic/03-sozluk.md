# Alan sözlüğü (ubiquitous language)
| Terim | Anlam |
|---|---|
| Organization | bir hastane/klinik işletmesi; organizasyon sınırı |
| Branch | belirli konum ve IANA saat dilimiyle şube |
| Department | şubeye bağlı bölüm (ör. Kardiyoloji) |
| ServiceDefinition | organizasyonun tanımladığı sağlık hizmeti katalog kavramı |
| BranchService | belirli şubede sunulan hizmet, ücreti, para birimi, süresi |
| StaffProfile | çalışan kimliği/profili; doktor veya diğer personel türü |
| StaffAssignment | personelin bir şubeye ve bölüme atanması |
| StaffServiceEligibility | personelin atandığı şubede hangi hizmeti verebildiği |
| OpeningHours | şubenin haftalık hizmet saatleri |
| WeeklyAvailability | personelin şube bazında rutin uygunluğu |
| AvailabilityException | belli gündeki izin/özel çalışma saati (tam gün veya interval) |
| Appointment | belirli hasta, çalışan, hizmet, şube, başlangıç-bitiş ve durum |
| Booking interval | yarı açık `[start,end)` zaman dilimi: bitişte yeni randevu olabilir |
| Snapshot | fiyat, süre, hizmet adının rezervasyon anındaki sabit kopyası |
| Pending | randevu oluşturuldu, henüz yetkili personel/yönetici onaylamadı |
| Tenant scope | organizasyon ve şube yetki sınırları; URL'ye güvenilmez |
| Definition of Done | kod, test, doküman, review ve demo kabulünün tamamı |
